## 🪄 クマへの「魔法の合図」一覧

| リオックマが言うこと | クマがやること（Gitコマンド） | 魔法の意味 🌟 |
| :--- | :--- | :--- |
| **「今の作業を保存して！」** | `git add .` <br> `git commit -m "..."` | 今作ったものを「日記」に書き込むイメージ！あとから見返せるようになるよ。 |
| **「新しいブランチ作って！」** | `git checkout -b feature/...` | 今のファイルを汚さないように、新しい「下書き用紙」を用意するよ！ |
| **「GitHubに送っておいて！」** | `git push` | 自分のパソコンの中にある日記を、ネット上の本棚（GitHub）に預けるよ。 |
| **「メインに戻して！」** | `git checkout main` | 下書きから、元の「本番用」の場所に戻るよ。 |
| **「今の作業を合体（マージ）して！」** | `git merge feature/...` | 下書きで書いた良い内容を、本番用の紙にきれいに写し取るよ！ |
| **「今までの履歴を見せて！」** | `git log --oneline` | これまでどんな魔法を使ってきたか、一覧で教えてあげるね。 |

## 🐻 クマのGit豆知識（リラックマ風）

### 🍯 なぜGitを使うの？
リラックマがだららんとしていても、Gitがあれば安心！✨  
「あ！さっきのほうが可愛かったのに！」って思っても、Gitで保存していれば、**魔法で時間を巻き戻せる**んだよ。🐾

### 🐾 ブランチってなに？
「お団子を食べるブランチ」と「ホットケーキを食べるブランチ」を分けるようなものだよ。🍡🥞  
お団子を食べている最中にホットケーキが混ざらないように、**別々の作業スペース**を作るんだね。

### 📦 コミットってなに？
日記に「今日はここまで頑張ったよ！」ってシールを貼る感じかな。💮  
こまめにシールを貼っておくと、あとでリオックマが「いつ何を頑張ったか」がすぐわかるようになるよ。
