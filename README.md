## 🛠 本ポートフォリオの設計・技術的工夫点

本ポートフォリオサイトは、単なる制作物の羅列ではなく**「閲覧者（ユーザー・採用担当者）の快適な操作体験」**を最優先に設計・実装しています。

### 1. スマホファースト & メンタルモデルに沿ったUX設計
* **ヘッダーメニューの一貫性**: 全ナビゲーションをページ内セクションへのスムーズスクロールに統一し、「メニュー = 全体の目次」「各カードのボタン = 個別詳細へ進む」という明確な操作モデルを確立。
* **画面サイズの最適化**: モバイル表示での文字の圧迫感を防ぐレスポンシブタイポグラフィと、狭い端末でも快適に読める余白（パディング）設計。
* **ヘッダーのスタビリティ**: スクロール時のレイアウトシフト（高さの揺れ）を排除し、タップ時のスクロール停止位置を正確に制御（`scroll-padding-top`）。

### 2. PageSpeed Insights を意識したパフォーマンス最適化
* **画像アセットの軽量化**: 2800px超の元画像をWeb最適サイズ（幅800px）へ約86%容量圧縮。
* **非同期・遅延読み込み**: ファーストビュー外の画像に `loading="lazy"` / `decoding="async"`、明示的な `width`/`height`（CLS防止）を付与。
* **メインスレッドの負荷低減**: スクロール連動や初期アニメーション処理を `requestIdleCallback` / `requestAnimationFrame` で非同期遅延実行し、強制リフロー（Forced Reflow）を解消。

### 3. Webアクセシビリティへの配慮
* **WCAG AA コントラスト比の準拠**: テキスト色と背景色のコントラスト比 4.5:1 を上回る **5.8:1** 以上を確保し、視認性を担保。
* **マシンリーダブルなHTML5構造**: セマンティックタグ（`<header>`, `<nav>`, `<main>`, `<section>`, `<article>`, `<footer>`）とスクリーンリーダー配慮。

## 📱 サイト構成

```text
portfolio/
├── index.html                  # メインポートフォリオ（全体目次・サマリー）
├── school.html                 # 学校紹介＆学生スタッフ活動詳細
├── foreign-internship.html     # 海外研修（西海岸IT企業視察）詳細
├── robot.html                  # メイクブラシ洗浄ロボット詳細
├── ux-design.html              # モバイルアプリUXデザイン詳細
├── beauty-sns.html             # 美容垢SNS運用詳細
├── creative.html               # クリエイティブ（Photoshop/Premiere Pro）詳細
├── css/
│   └── style.css               # カスタムアニメーション・基本スタイル
├── js/
│   ├── main.js                 # ナビゲーション制御・クマギミック
│   └── tailwind-config.js      # テーマカラー・デザインシステム定義
└── photo/                      # 最適化済み画像・ドキュメントアセット
```
